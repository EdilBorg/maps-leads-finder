# Linear — Style Reference
> midnight precision instrument

**Theme:** dark

O frontend do Maps Leads Finder segue estes tokens. Ver index.html para implementação.

## Cores principais

| Token | Valor | Uso |
|-------|-------|-----|
| Void | `#08090a` | Canvas |
| Carbon | `#0f1011` | Cards / painéis |
| Obsidian | `#161718` | Superfícies elevadas |
| Graphite | `#23252a` | Bordas |
| Fog | `#8a8f98` | Texto secundário |
| Mist | `#d0d6e0` | Texto corpo |
| Paper | `#ffffff` | Títulos |
| Acid Lime | `#e4f222` | CTA principal (único) |
| Pulse Green | `#27a644` | Sucesso / sem website |
| Coral Red | `#eb5757` | Erros |

## Regras

- Um único botão cromático por vista (acid lime)
- Bordas hairline, sem sombras decorativas
- Radius: cards 12px, botões/inputs 6px
- Tipografia Inter 400–510
- Densidade compacta, ferramenta de trabalho
